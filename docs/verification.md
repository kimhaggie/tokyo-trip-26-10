## 남은 확인 사항

- **LOLO**: 공식 사이트·SNS를 찾지 못함. 주소는 사용자 제공값, 사용자 지도 링크와 위치 일치. 10/31 영업일·시간 확인 필요.
- **BEAMS PLUS 마루노우치 · BEAMS MEN 시부야 · BEAMS JAPAN 신주쿠 · 빅카메라 신주쿠 동쪽 출구점**: 이 작업 환경에서 공식 페이지가 응답하지 않아 직접 확인하지 못했다. 주소·영업시간을 “확인 필요”로 표시 (조사 참고값만 메모).
- **Satella**: 공식 사이트가 닫혀 있음. 타베로그와 다른 사이트의 영업시간이 다름 → 방문 전 확인.
- **SEIKO SBTH007**: 재고 확인하지 않음.
- **Good On**: 영업일을 달마다 공지하는 경우가 있음 → 10월 말 공지 확인.
- **N'EX**: JR 동일본 공식 페이지 본문을 직접 열지 못함. 열차·운임·터미널은 예약할 때 확인.
- **항공사·터미널**: 제공되지 않음.
- **도쿄역 짐 보관**: 방식·장소 미정 (선택지는 준비 탭).
- **기쿠카와 서비스료 10%**: 공식 메뉴에서 확인하지 못해 표시하지 않음.
- **할로윈 교통 대책**: 정확한 시각·구역은 공식 PDF 지도에만 있어 그리지 않음.
